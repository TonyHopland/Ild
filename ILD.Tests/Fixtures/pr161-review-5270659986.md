`ILD.Core/​Services/​Implementations/​RemoteProviders/​AzureDevOpsRemoteGitProviderAdapter.cs:285`

This uses `GetArrayAsync`, whose contract is to turn HTTP/JSON failures into an empty list, and it makes only one threads request. A transient Azure failure therefore looks like a valid empty ledger, while a pull request beyond the endpoint's response limit silently loses its tail; the heartbeat can then seed or operate on an incomplete view. Use a failure-aware paginated threads read and return `Unavailable` when the complete ledger cannot be read.
</details>

This only removes the pending intent; it never undoes the delivery-ledger entry that caused the round. Re-arm the corresponding ledger item atomically when a queued reply or resolve is dropped.
